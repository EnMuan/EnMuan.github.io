Games

About this project

A 2D platformer built in Unity from the 2D Platformer Microgame template, with time manipulation as the core mechanic. I wrote two abilities that share one energy bar: Time Stop, which slows the world to 30% speed while the player moves normally, and Player Slow, which slows the player's own movement and fall speed while held. Collecting tokens restores energy, so players have to manage when to use each ability. I also built the main menu, an in-game menu with rebindable keybinds, and a victory zone at the end of the level. Making the player ignore the global time scale meant reworking the template's physics code to use unscaled time.
