About this project

A Unity-based playable experience built on the “Stay Healthy” base project, expanded into a complete start-to-finish game loop. Integrated systems include a UI fader/scene transition, a key-and-door unlock mechanic, an AI companion that follows and attacks on command, a turret with projectile logic, a dynamic day/night cycle, and a win condition leading to a victory screen with replay/exit options. Demonstrates range across UI systems, gameplay mechanics, basic AI behavior, and game state management.
