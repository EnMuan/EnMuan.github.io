Rex — 3D Model

3D Art

About this project

A game-ready character model built in 3ds Max under a strict 2,500-polygon budget, with hand-painted PBR textures in Substance Painter. Rigged and animated using Biped with freeform keyframing, then exported through an FBX pipeline into Unity, where I resolved Animator Controller compatibility issues (Legacy vs. modern setups), fixed action-animation freeze bugs, and implemented death-animation toggle logic.
